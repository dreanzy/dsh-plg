# 07 设置页

Status: ready-for-agent
Type: task
Blocked by: 06

## 目标

插件页里的「模型方案」条目：增删方案、编辑档位、绑定工作区。

## 范围

`client/client.js`。注册进 `plugins.item` slot。要求：方案列表带会话路由与四档摘要；每档的首选/备选是有序列表，每条含模型与思考等级两个下拉，强度选项来自该模型的 reasoning.efforts；「跟随」是独立按钮（提交 null 删除键），不是下拉里的空选项；出厂方案无删除按钮；删除仍被绑定的方案时要求先解绑或确认回落。

样式照 `docs/ui-baseline.md` 与现有三个插件的 panel 实现。

## 验收

手工验证四项：新建方案后刷新仍在；改档位后新会话生效；工作区绑定后新会话用该方案、旧会话不变；删除方案后面板不再列出。

## 边界

不改官方设置页；不加 composer 控件。

# dsh-lsp-lens

把语言服务器的诊断在改完代码后回灌给模型的 DSH 插件。本节只收本插件独有的词；DSH 装配语义与仓库约定（工作区、会话目录、profile、entry）见[根术语表](../../GLOSSARY.md)，这里不重复定义。

## 术语

**提醒（Nudge）**:
改措辞，让模型自己想起来调用 `lsp_diagnostics` 一类工具。它不改变模型已经看到的内容，只影响下一次决定。
_Avoid_: 注入、提示、引导

**回灌（Feedback）**:
把诊断文本放进模型上下文。落地位置有两个：写入类工具的返回里追加，或下一步开头追加。回灌不依赖模型主动调用任何工具。
_Avoid_: 注入、推送、反馈注入

**发现来源（Source）**:
一条能指出「哪些文件变了」的路径。本插件有三个：写入类工具的返回、`fs/observed` 文件观测、git 差分的 `git status`。三者只负责发现，不负责判定。
_Avoid_: 通道、钩子、触发器

**脏文件（Dirty file）**:
内容版本已变、尚未被诊断过的受支持文件。以绝对路径加内容版本识别，同一版本只诊断一次；三种发现来源只是找到它的方式。
_Avoid_: 变更文件、待诊断文件、修改文件

**受支持文件（Supported file）**:
扩展名在本 profile 的 LSP 服务器表里有归属的文件。其余扩展名不进回灌，也不产生诊断调用。
_Avoid_: 可诊断文件、目标文件

**待处理（Pending）**:
诊断里存在 error 级问题、尚未处理。回灌时标为待处理，要求模型在宣告完成前处理它。
_Avoid_: 阻断、STOP、错误

**告知（Notice）**:
warning 与 info 级诊断，只供参考，不要求动作。
_Avoid_: 警告、提示、advisory

**未确认（Unconfirmed）**:
诊断没有拿到可信结果：服务器未就绪、调用超时、或返回被标为不完整。未确认不等于干净，回灌必须显示这个状态。
_Avoid_: 空结果、无诊断、干净

## 边界

- 脏文件的路径基准是**会话目录**（`workingDirectory` 投影），不是 `header.cwd` 快照；`cd` 之后产生的写入按新目录判定。
- 「工作区」在本插件里只用于解释 LSP 服务器的路由范围，不作为脏文件的键——文件按绝对路径识别。

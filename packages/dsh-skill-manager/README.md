# @dreanzy/dsh-skill-manager

按工作区控制 skill 可见性的 DSH 插件。全局层给默认值，每个工作区可逐项或按分组覆盖，两个方向都行。

[English](README.en.md) | **简体中文**

## 它解决什么问题

装得多之后，每一轮请求都要重新付一遍清单成本：skill 目录进上下文、候选太多让模型选错、A 项目的专用能力在 B 项目里一直占位。

本插件把「模型此刻能自动调用哪些 skill」变成一组开关，分两层：

```
工作区项级  ??  工作区组级  ??  全局项级  ??  全局组级  ??  默认开
```

前一环存在就不读后面的。**工作区的任何决定都压过全局的任何决定**——否则会出现「在工作区点了开、界面显示开、模型看不见」这类最难排查的状态。

## 分组

分组是策略的一层，不是批量写入的快捷方式：

- 一个 skill 最多属于一个分组，未归属的就是未分组。
- 点一个组开关只写一条决定，组内后加入的成员自动跟随。
- 组开关只显示组级值（跟随 / 开 / 关），不被组内项级覆盖污染；组行会标出「N 项单独覆盖」。
- 组定义跨工作区共享，开关按层各存一份。重命名分组不影响任何已保存的决定。

## 安装

```sh
dsh plugin --profile <profile> add @dreanzy/dsh-skill-manager
```

重启 Host、刷新页面。三个入口：侧栏「Skill 管理」、输入框右侧「Skills」、设置 → Skill 管理。三处都能开关；侧栏入口本身可以在设置里关掉。

## 编辑与保存

面板里的拨动只改本地草稿，底部浮出「保存 / 撤销」：

- 连拨十次也只发一条请求，界面不会被乱序返回的旧响应覆盖。
- 保存失败时草稿保留，可以直接重试。
- 关闭弹层等同撤销。
- 分组的新建、改名、删除与「移动分组」是即时写入，不参与草稿——它们改的是跨工作区共享的组定义，草稿会让人误以为能撤回。

详见 [docs/adr/0005-draft-and-save.md](docs/adr/0005-draft-and-save.md)。

## 面板

- 「未分组」恒在最上；其余分组按本层生效值排序，开的在前、关的在后。组内同样开在前，状态相同的按名字排。
- 每行名字右侧标出来源：`.agents`、`.dsh`、`官方`、插件名或 `运行时`。
- 组行显示组级值，并标出组内被单独覆盖的条数；项行有覆盖时出现 ↺，点它回到跟随。

## 文件

| 路径 | 内容 |
| --- | --- |
| `$DSH_HOME/skill-manager/global.json` | 全局层的项级与组级决定、`showOfficialSkills`、`showSidebarEntry` |
| `$DSH_HOME/skill-manager/groups.json` | 分组定义与成员归属，跨工作区共享 |
| `<cwd>/.dsh/skill-manager.json` | 某个工作区的那一层 |

工作区文件算工程约定：它与 `.dsh/skills` 同处一个目录，表达的是「这个工程需要哪些能力」，可以提交、可以共享。插件不碰 `.gitignore`——如果你的仓库整体忽略了 `.dsh/`，需要单独给这个文件加一条例外（`!/.dsh/skill-manager.json`）。

## 写入语义

每一次开关提交的是一组**意图**（`{层, 键, 值|null}`），服务端在文件锁内读—改—写，不比对任何版本。命令幂等、可交换，写同一键即后点者赢，因此不存在 `stale-revision` 这类冲突。`null` 表示删掉这条键、回到跟随——写一个同值不等于跟随。

详见 [docs/adr/0001-intent-writes.md](docs/adr/0001-intent-writes.md)。

## 已知边界

- **只管 skill**。MCP 的按工作区开关不在本包范围（MCP 一侧在 DSH 里没有干净的收窄点）。见 [docs/adr/0004-skill-only-scope.md](docs/adr/0004-skill-only-scope.md)。
- 会话中途切换工作目录不会重算策略，重开会话即恢复。
- 同层 first-wins：若别的插件先把同名 skill 注册进同一层，那条关不掉，面板会标灰并说明原因。
- 官方 `@deepseek-ai` 技能默认不在面板出现（判定见 `src/inventory.ts`），但模型仍可调用；打开「显示官方技能」后可逐项关闭。

## 与 dsh-skill-scope 的关系

两者都往 Agent 同层注册遮蔽副本，**不能共存**，装本插件前请卸载它。本插件不读它的配置，迁移需要手动重配。
